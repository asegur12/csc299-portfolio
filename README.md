# csc299-portfolio
A collection of 3 projects that are a part of my CSC299 class final

## Projects

| Project | Type | Repository | What it does |
|---|---|---|---|
| Stock Grader | Web app | https://github.com/asegur12/stock-grader | Shows the 10 most valuable stocks, their price history and news, and a 1-week estimate. Live: https://asegur12.github.io/stock-grader/ |
| Magic Rush (formerly Slaughtermate) | Game | https://github.com/asegur12/Project-2-Slaughtermate | An offline fantasy hack'n'slash (with an optional chess theme): 7 floors, 8 weapons, 125 spells, secret bosses and an Endless mode. Developed over 6 rounds. |
| Grade My Device | Command-line app | https://github.com/asegur12/device-grader | Scans your computer's storage and hardware (read-only) and grades it against college and office-job standards. |
